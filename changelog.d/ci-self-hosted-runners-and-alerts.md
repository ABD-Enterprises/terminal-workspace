- [INTERNAL] CI jobs now select their runners through variables rather than fixed labels — `LINUX_RUNNER_LABELS` for Validate's Linux jobs and CodeQL, `MACOS_RUNNER_LABELS` for the Rust build/test job, and `RELEASE_MACOS_RUNNER_LABELS` for the signing release job (whose fallback matches no runner on purpose) — so re-pointing CI is a variable change, not a workflow edit. Every checkout starts from fresh Git metadata and no longer persists the token.
- [SECURITY] Bump transitive packages in pnpm-lock.yaml: shell-quote 1.10.0 → 1.12.0 (Dependabot alert 49, critical) and source-map-js 1.2.1 → 1.2.2 (alert 48, high) via `pnpm.overrides`. The Rust `glib` advisory (alert 6) is dismissed as a tolerable risk: tao target-gates gtk to Linux/BSD, so the shipped macOS app never links glib, and the 0.20 fix is unreachable while gtk stays at 0.18.
