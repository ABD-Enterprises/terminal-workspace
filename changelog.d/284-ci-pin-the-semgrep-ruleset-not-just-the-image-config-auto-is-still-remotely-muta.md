- [INTERNAL] The semgrep gate now runs against a pinned ruleset: a git submodule of semgrep/semgrep-rules at one commit plus a generated manifest (.semgrep/rules.tsv) of the c/auto rule ids resolved to files, with metrics off and no registry fallback, so nothing is fetched at scan time. The rules are never copied into this public repo (Semgrep Rules License v1.0 forbids redistribution). Owner, 90/120-day cadence (enforced by validate.sh), parity numbers and the refresh script are recorded in .semgrep/README.md. (#284)
