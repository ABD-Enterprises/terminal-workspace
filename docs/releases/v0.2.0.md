# Terminal Workspace v0.2.0

> **Status: tagged, never published.** `v0.2.0` exists only as a git tag; no GitHub release was created for it and no download assets exist. The only published release remains `v0.1.0`. If this tag is ever published, rewrite this banner first — it is prepended to the release body verbatim.

This tag makes the signed updater artifacts (`latest.json`, `.app.tar.gz`, `.sig`) a hard requirement of the release workflow for the first time — promotion there now fails if they are missing, instead of skipping them the way it did for v0.1.0; local promote runs still skip by design. Because the version was never published, no update feed was ever served from it and no v0.1.0 install was ever offered this update.

## Install
This version was never published, so there is nothing to download. The steps below describe installing the app that a build from this tag produces:

1. Build from the tag following `docs/release.md`, producing **terminal-workspace-macos-v0.2.0.app.dmg**. Without a Developer ID certificate the release check refuses to build; without a notary keychain profile `native:dmg` skips and no DMG appears. `npm run native:bundle:preview` builds an unsigned bundle instead, with no DMG.
2. Open it and drag **Terminal Workspace** into **Applications**.
3. Launch it from Applications. The app inside the runbook's DMG is signed with a Developer ID certificate; the DMG itself is notarized by Apple and stapled. Apple Silicon (arm64), macOS 13+.

## What changed
- **Diagnostics logging.** The packaged app now writes rotating log files (`~/Library/Logs/com.abdenterprises.terminalworkspace/`) and key-management failures are logged with a reason; see `docs/support-bundle.md` for what to attach to a bug report.
- **Typed connection errors.** Connect failures carry a stable category (timeout, refused, DNS, auth failed, host key mismatch) so the pane shows the right message and hint instead of a raw string.
- **Host key mismatch is terminal.** A host presenting a different key than the one you trusted no longer triggers automatic reconnect attempts; re-scan and trust the new key explicitly.
- **One app instance.** Launching the app while it is running focuses the existing window.
- **Database rename.** The local SQLite file is now `terminalworkspace.db`; your existing data is migrated in place on first launch (the old file is left untouched).
- **Passphrases never on argv.** Generating a key with a passphrase no longer exposes it to other local processes, and a validation gate now prevents that class of bug from returning.
